# SIH26085 — Urban Flood Nowcasting System

Smart India Hackathon 2026 entry for problem statement **SIH26085**
(Ministry of Earth Sciences / NCMRWF). Forecasts which streets in a Chennai ward
will flood in the next 0–3 hours by coupling a rainfall nowcast with a drainage
network model, and suggests routes that avoid the flooding.

## Setup
```
python -m venv .venv
.venv\Scripts\activate          # Windows
pip install -r requirements.txt
copy .env.example .env          # then fill in the values
```

## Layout
`data/raw` is downloaded and never edited. `data/interim` and `data/processed` are
regenerated by scripts. `src/` holds the pipeline, `tests/` mirrors it, `outputs/`
holds figures and model runs, `deck/` holds the presentation, `handoffs/` and
`research/` hold dated documents. Full rules in the keep-organised skill.
